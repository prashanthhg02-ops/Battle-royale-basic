# Last One Standing

A small, playable 2D battle royale game that runs directly in a web browser. There are no dependencies or build steps.

## Run the game

1. Open `index.html` in a modern web browser.
2. Select **Start match**.
3. Survive the other 11 players and stay inside the safe zone.

## Controls

| Action | Controls |
| --- | --- |
| Move | `W`, `A`, `S`, `D` or arrow keys |
| Aim | Mouse |
| Fire | Click and hold, or press and hold `Space` |

## Gameplay

- Fight 11 computer-controlled opponents in a top-down arena.
- Use the obstacles for cover.
- Watch your health and the survivor count in the HUD.
- The safe zone begins shrinking after a short delay. Players outside it take damage.
- Win by being the last player standing. Start another match with **Play again**.

## Project files

- `index.html` — the game, styling, and JavaScript are self-contained in this file.
